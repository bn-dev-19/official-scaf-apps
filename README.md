# official-scaf-apps

`scaf/` is an **application scaffolding project** : a complete specification of an application, broken down into small, diff-friendly YAML/JSON files. Based on this spec, the SCAF tool (or a manual process) generates artifacts such as OpenAPI definitions, SQL/Drizzle schemas, documentation, task tickets, and the source code for a target application
